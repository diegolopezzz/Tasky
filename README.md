# Tasky

Aplicación web sencilla para organizar tareas y hábitos. Los datos se guardan
en el almacenamiento local del navegador.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Ejecutar en desarrollo

Desde la carpeta `tasky-app`, instala las dependencias y arranca el servidor:

```bash
npm install
npm run dev
```

Abre en el navegador la dirección local que muestra Vite, normalmente
`http://localhost:5173`.

## Comprobar la compilación

```bash
npm run build
```

Los archivos listos para producción se generan en `dist/`.
